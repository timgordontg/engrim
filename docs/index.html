The Structural Problem: Container Amnesia

Modern cloud CI/CD (GitHub Actions, Kubernetes ARC runners, ephemeral pods) was engineered for stateless, deterministic bash scripts. When autonomous agents (Claude Code, Antigravity, GitHub Agentic Workflows) execute multi-turn triage, automated SRE, or iterative refactors in CI:

01 / Pod Teardown Amnesia

Every runner shutdown wipes local files. Next runner spins up blind, forcing agents to re-explore the codebase and repeat identical failed hypotheses.

02 / Compaction Collapse

Raw build traces exhaust 128k/200k token windows in minutes. Native LLM context compaction drops subtle architectural invariants, introducing silent regressions.

03 / Cross-Model Blindness

Heterogeneous model ensembles (e.g. o3 for planning, Claude for implementation, Antigravity for QA) lack a shared, persistent state bus between steps.

Core Engine Architecture

Sub-4k Precision Boot Packs

Deterministic curation budget. Loads high-signal decisions, measured outcomes, and active invariants in under 4,000 characters—leaving context windows clear.

Hybrid Search Retrieval

Fast reciprocal rank fusion combining BM25 keyword matching with dense local vector embeddings. Sub-5ms retrieval over thousands of historical decisions.

PreCompact Invariant Capture

Intercepts model sessions at the moment architectural choices and test feedback occur. Prevents degradation during automatic context window compaction.

Native Lifecycle Hooks

Standard JSON hooks for Antigravity, Claude Code, Cursor, OpenAI Codex, and standalone CI runner environments. Zero custom plugins required.
